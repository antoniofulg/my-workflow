# QA personas

## Workflow adopter

A developer adding the workflow to a new or existing repository. They need a reviewable adoption
that preserves product-owned material and uses the target's real QA capabilities.

## Workflow operator

A developer running the installed workflow. They need Deep Review to preserve valid work, report
observational metrics honestly, and continue when optional telemetry or repository maps are absent.

## Repository reader

A maintainer or community member evaluating what the workflow ships, where it came from, and which
release contract is current.
